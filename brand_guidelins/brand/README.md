# DriverWatch Brand Assets

Ready-to-use files for your website.

## Logo Files (SVG - recommended for web)

| File | Usage |
|------|--------|
| `logo-primary.svg` | Main logo (icon + wordmark) – headers, nav |
| `logo-icon-only.svg` | Favicon, app icon, small UI |
| `logo-stacked.svg` | Vertical layouts, mobile, centered sections |
| `logo-reversed.svg` | Dark backgrounds / hero sections |
| `logo-monochrome.svg` | Single-color / print / special cases |

## Colors

```css
--dw-navy: #0A2540;   /* Primary */
--dw-teal: #5B8A9A;   /* Accent */
--dw-white: #FFFFFF;
--dw-soft-gray: #F2F4F7;
```

See `colors.css` for ready-to-copy CSS variables.

## How to use on website

```html
<!-- Primary logo -->
<img src="/assets/logo-primary.svg" alt="DriverWatch" height="40">

<!-- Or inline the SVG for perfect control -->
```

## Brand Rules (quick)

- Keep the steering wheel small (iris size)
- Never stretch or distort the logo
- Minimum clear space = height of the eye icon
- Prefer the navy + teal version on light backgrounds
- Use reversed version on dark navy backgrounds
